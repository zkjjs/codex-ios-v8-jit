# Codex 额度 — iPhone 应用设计

日期：2026-10-25。状态：设计待确认，尚未开始编写或编译应用。

## 已确认目标

制作可签名安装的 iPhone IPA，查看本人 ChatGPT 账号的 Codex 订阅额度。支持 OAuth 登录、原生液态玻璃 UI、桌面小组件，以及下一次额度重置时间。显示中文，适合手机查看。

## 实现方案与取舍

采用 SwiftUI + WidgetKit，主应用直接访问账号服务，不要求用户额外部署服务器。登录使用 Codex 的设备码 OAuth 流程：应用生成一次性授权码，用户前往 OpenAI 官方网页完成登录，返回应用后继续取得授权结果。登录流程遵循官方开源 Codex 的实现；它不是已经完成第三方客户端注册和实机验证的承诺。接入阶段必须首先验证客户端授权是否允许以及额度接口是否可访问，失败时显示真实错误，不改为模拟额度。

备选一：自建服务运行官方 Codex app-server，手机读取服务返回的额度。接口更贴近官方客户端，但新增服务器运维、远程凭证保管与访问控制，不符合本次便捷独立使用的目标，暂不采用。

备选二：在应用中嵌入额度网页。难以可靠地给 WidgetKit 提供结构化数据，无法满足小组件要求，暂不采用。

以上是开发建议；用户已确认账号额度、液态玻璃和重置时间需求，尚未确认本文中的实现细节。

## 界面

- 首页顶部：应用名称、账号套餐、刷新按钮；账号邮箱可隐藏。
- 主要内容：额度窗口的剩余百分比和进度条；如接口返回短周期与周额度，则分别展示。窗口长度以服务器结果为准，不把所有账号写死成固定周期。
- 每个窗口展示重置的本地日期、时间和剩余时长；跨日明确显示日期。
- 底部显示最近成功更新时间，以及离线、登录失效、接口不可用等状态。
- 设置页包含账号管理、退出登录、显示隐私及小组件添加说明。
- 未登录状态显示实际登录入口，不显示看似真实的示例额度。

界面使用系统原生 Liquid Glass API；导航、按钮、账号控件采用玻璃效果。额度数字保持高对比度，不让多层透明背景影响阅读。跟随系统深浅色、动态字体及降低透明度偏好。最低系统目标为 iOS 26；以所用稳定版 Xcode SDK 能够编译和运行的 API 为准，避免依赖未经验证的 iOS 27 专有接口。

## 小组件

提供小号和中号桌面小组件：

- 小号：主要额度的剩余百分比、最近一次已知的重置时间、倒计时和数据时间。
- 中号：短周期及较长周期的剩余额度、各自重置时间，并标记最近将要发生的重置。
- 支持点按进入应用刷新。倒计时使用系统日期渲染，无需每秒网络请求。
- 使用系统支持的小组件背景和着色方式；小组件背景材质由桌面显示模式决定，不承诺与应用内的玻璃效果完全相同。

显示逻辑：只从实际返回的额度窗口中计算最近的未来重置时间。接口未返回时间则显示“重置时间未知”。已知时间已过但还未取得新数据时，显示“已到重置时间，待更新”，不得自动将额度设为 100%。如果某个窗口没有额度信息，不以零或满额代替未知。

刷新策略：应用打开、回到前台、手动刷新时拉取；小组件申请约 30 分钟后及已知重置时间之后的刷新，实际执行由 iOS 调度。网络失败保留最后成功快照并明确标注旧数据。遇到 429 遵循 Retry-After 并退避，不持续轮询。

## 登录、凭证与共享数据

应用只在 OpenAI 官方网页输入账号密码，不在自制页面收集密码。设备授权码有到期时间，可取消和重新生成；切回应用后恢复合理的轮询，不依赖在后台持续执行。该流程需要账号允许设备码登录；不可用时给出官方设置说明。

OAuth 凭证存入系统 Keychain，不写入日志、构建产物、代码仓库或普通 UserDefaults。主应用拥有刷新令牌；小组件仅从共享 Keychain 读取当前有效的访问令牌进行额度查询，不竞争刷新令牌。令牌过期时显示缓存并提示打开应用更新。使用同一 App Group 共享不含令牌的额度快照和状态。退出登录立即清除令牌与快照，并请求刷新全部小组件。

首版只支持一个账号，不实现账号轮换、API 余额、CPA 管理、聊天功能或消耗额度的推理请求。

## 构建与安装

交付目标：包含 Widget Extension 的未签名 IPA、完整源码和可复现的 macOS 构建配置。未签名 IPA 需要另行签名安装。

当前执行环境为 Linux，没有 xcodebuild，不能在本机编译 iOS。需要接入 macOS 构建环境，例如 GitHub Actions；不得将源码压缩包称作已编译 IPA。是否可创建独立 GitHub 仓库、运行构建以及获取产物，在开发阶段以实际可用能力为准；当前没有修改任何已有仓库。

签名时主应用和小组件扩展必须属于同一团队，并保留可用的 App Groups、Keychain 共享权限和嵌入扩展。安装器移除扩展或签名配置不支持共享容器时，小组件功能可能不可用；应用应检测共享容器失败并给出明确提示。

## 验收

1. macOS 构建成功，IPA 包内存在主应用和 Widget Extension。
2. 本人账号在 iPhone 官方网页完成授权，应用读取真实的剩余额度及重置时间；未验证前不宣称登录已实测可用。
3. 数据模型测试覆盖百分比边界、缺失字段、仅单个窗口、时间缺失和已经过期的重置。
4. WidgetKit 快照验证小号、中号；长日期、动态字体和深浅色布局可读。
5. 离线、401、429、令牌过期、取消登录和退出登录均有明确状态；不泄露令牌，不制造新额度数据。
6. 实机签名安装后验证应用与小组件的数据共享；不能仅凭编译成功宣称小组件可用。
